# Pokémon Team Viewer

## Description

A pokemon team viewer that lets you organize a predefined pokemon team, and see further details

## Technologies Used

React + Vite

## Features

Allows addition and removal of specific pokemon, as well as selecting specific pokemon and seeing additional details. Prevents duplicates, and prevents a deleted pokemon from being selected. 

## Installation and Setup

Open in code viewer of choice, ideally vs code, and open terminal. Enter npm install to install the project's dependencies, and then enter npm run dev and put the http address into to see code implemented and ran

## Known Limitations

Only has a predetermined list of pokemon with only the ability to select, add, or remove.
